# Price Tracker Scraper

A clean, production-ready Python script designed to extract product data (names and prices) from web pages and save it into a structured CSV file.

This tool is perfect for market research, price monitoring, or building a dataset for further analysis.

## Features

- **Fast & Reliable:** Uses `requests` with custom headers to avoid basic blocks.
- **Clean Parsing:** Built with `BeautifulSoup4` to easily navigate HTML trees.
- **Data Export:** Automatically formats and saves data to `prices.csv` with timestamps.
- **Zero Dependencies Bloat:** Only requires two lightweight libraries.
